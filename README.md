# mcbot —— Minecraft 假人（mineflayer）

自动狩猎 **mooshroom / cow**、拾取掉落物、自动进食、自动存仓的挂机假人，带 **网页实时监控**（3D 直播视图 + 远程控制）。
基于 [mineflayer](https://github.com/PrismarineJS/mineflayer) + [mineflayer-pathfinder](https://github.com/PrismarineJS/mineflayer-pathfinder) + [prismarine-viewer](https://github.com/PrismarineJS/prismarine-viewer)，Node.js >= 18。

## 快速开始

```bash
npm install                 # 安装依赖
cp .env.example .env        # 编辑 .env 填入服务器信息与密码
npm start                   # 待机模式：登录后等网页唤醒
npm run start:auto          # 或 --auto-start：登录后直接开始工作
```

`.env` 配置项：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `HOST` | 服务器地址 | `localhost` |
| `PORT` | 服务器端口 | `25565` |
| `BOT_USERNAME` | 假人用户名（离线模式） | `mcbot` |
| `VERSION` | 服务器版本，**必须与服务器完全一致** | `1.21.11` |
| `AUTH` | `offline`（离线+AuthMe）/ `microsoft`（正版） | `offline` |
| `PSW` | AuthMe `/login` 密码（**必填**，缺失则退出） | - |
| `WEB_PORT` | 网页监控台端口 | `3000` |
| `VIEWER_PORT` | 3D 视图端口 | `3001` |

## 网页监控

浏览器打开 `http://<服务器IP>:3000`：

- **3D 直播视图**（iframe）：以 bot 视角实时渲染世界，支持
  - 相机模式：**轨道 / 第一人称 / 第三人称 / 俯视图** 一键切换；
  - **帧率可调**：3D 渲染 fps（0=不限）与状态刷新 fps 两个滑条；
  - 实时显示方块、牛/蘑菇牛、其他玩家、掉落物与 bot 模型。
- **工作状态卡片**：坐标/朝向/生命/饱食度/饱和度/维度/当前目标/物品栏/手持武器/附近玩家/待拾取掉落/运行时长。
- **聊天**：查看**其他玩家的聊天**与系统消息，输入框可直接聊天或发指令（如 `/home work`）。
- **暂停/唤醒**：不带 `--auto-start` 启动时，登录后**待机**，点「唤醒」按钮才开始工作；工作中可随时「暂停」。

> 3D 视图（`VIEWER_PORT`）可直接独立访问 `http://<服务器IP>:3001`。

## 行为流程

1. **登录**：进服 1.5s 后发送 `/login <PSW>`，1s 后发送 `/home work`；`--auto-start` 则直接开工，否则待机等网页唤醒。
2. **狩猎**：
   - 在 50 格内寻找 `minecraft:mooshroom` 与 `minecraft:cow`，**mooshroom 优先**，同类型取**最近**的；
   - 寻路接近并保持 **≥2 格**距离（2.5 格停靠），切到**最好的剑**（下界合金 > 钻石 > 铁 > 石 > 金 > 木）攻击直到目标死亡；
   - **面向移动方向**：寻路开始前先面向目标，寻路中每 150ms 面向下一路径节点（部分服务器要求玩家面向移动方向才允许移动），并带卡住检测日志；
   - 死亡后拾取掉落物：**仅限假人自己参与击杀（最后攻击该目标 4 秒内死亡）、且目标死亡 3 秒内新生成、距死亡位置 <2 格的 `minecraft:item` 实体**，**其他玩家打死的牛/蘑菇牛掉落物不捡**。
3. **避让玩家**：寻路时靠近其他玩家的方向**权重降低**（4 格内代价递增），但不会完全无法通行。
4. **存仓**（物品栏满时）：
   - 先寻路到**周围 5 格内无目标**（mooshroom/cow）的可站立位置，再发送 `/home cangku`；
   - 等待 3.5s——期间**不移动、不拾取掉落物**，但附近有目标会**原地切剑攻击**；
   - **以系统聊天出现“传送完成”提示判定传送成功**（部分匹配），未收到则**重复 `/home cangku`** 直到成功；
   - 传送后寻找 10 格内的 `minecraft:barrel` 并打开，把背包中**除盔甲、剑、熟猪肉外**的所有物品移入容器，**限速 4 次/秒**（shift-click 整组）；
   - 容器满则**每 1s 查看空位**，超过 10s 无空位则**待机，每 10s 检查一次**；空位出现后继续存入；
   - 全部放入后发送 `/back`，同样以“传送完成”提示为准，超时重试。
5. **进食**：生命 <12 **且**饱和度 ≤19，**或**饱食度 <16 时，把熟猪肉放入副手（**仅当不在副手时**手动放入），食用直到副手数量减少（食用动作完成），**5 秒内不再食用**；**熟猪肉耗尽则下线**。
6. **死亡**：自动重生后发送 `/back`，以“传送完成”提示为准，超时重试。
7. **断线重连**：被踢/断线 5 秒后自动重连并重新登录（3D 视图随重连自动重建）。

## 服务器前提

- 离线模式 + AuthMe（或类似的 `/login` 密码插件）；
- 已设置家：`/home work`（狩猎点）、`/home cangku`（仓库点），且仓库点 10 格内有 `barrel`；
- `/back` 指令可用（死亡返回 / 仓库返回）。

## 注意事项

- 狩猎点 50 格内需要有牛/蘑菇牛，否则假人原地待机等待；
- 存仓期间不做进食检查（进食只在狩猎阶段触发）；
- 3D 视图：1.21.11 的客户端 bundle 与资源由 `npm run build:viewer` + `npm run gen:assets` 重建生成（仓库已附带产物，一般无需重建）；1.21.5+ 新增方块的纹理缺失时会显示棋盘格占位；
- 掉落物判定依赖实体事件顺序，假人会在目标死亡瞬间扫描一次死亡点 2 格内的物品实体兜底；
- 击杀归属：假人只拾取自己参与击杀（最后攻击 4 秒内死亡）的目标掉落物，其他玩家打死的掉落物不抢；
- 日志：时间戳 + 分类标签（`[状态]/[移动]/[路径]/[击杀]/[掉落]/[攻击]` 等），每 30 秒输出一次状态快照，寻路卡住会输出诊断日志，并实时推送到网页。
